# How this project was made

Reelwright implements a *concept*: take a long video, find the most shareable moments, and render them as
captioned 9:16 clips. Ideas, features and general workflows are not protected by copyright; specific code is.

- The code in this repository was written from scratch against that concept and the public behaviour of
  ffmpeg, Whisper-style transcription and OpenAI-compatible chat APIs.
- It does not copy code, prompts, schemas, UI, assets, names or branding from any other clipping project.
- Contributors must not paste code from projects whose licence is not compatible with Apache-2.0
  (including source-available or non-commercial licences). See CONTRIBUTING.md.

This is an engineering practice, not a legal opinion. If you plan a commercial product, have a lawyer review it.
