# Contributing

1. Fork, branch, and open a pull request.
2. Run `make check` (ruff + pytest) before submitting.
3. Sign off your commits (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/).
4. **Do not copy code** from projects with licences incompatible with Apache-2.0 (source-available, non-commercial,
   AGPL/GPL). Write your own implementation. If unsure, ask first.
5. Add tests for behaviour changes. Keep user-facing text free of third-party branding.

By contributing you agree your contribution is licensed under Apache-2.0.
